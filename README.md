# One Word, First Thought

Entry for the make.fun bounty
[u-0xkianno-one-word-first-thought-106abaf8](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8):
send exactly one word, the first that comes to mind — the most
interesting word takes the reward.

## The entry

**petrichor** — the smell of rain on dry earth after a long dry spell.

It is surprising rather than safe, vivid and specific (it calls up a
clear image and feeling in nine letters), and it carries a spark of wit
in its sound: the soft "petr-" of stone meeting the freshness of rain.
It is a chosen word, not filler like "thing" or "stuff".

## How it works

`main.py` (Python standard library only) writes exactly that one word,
with no trailing newline and no spaces, to `/output/entry.txt`.
The program is deterministic: every run produces byte-identical output.

Verified locally: the output file holds exactly 9 characters (one word,
no spaces), valid UTF-8, and passes the kit's gate of 1–24 characters.
